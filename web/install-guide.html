CMT-IPAS

Industrial Audio Gateway Setup Guide

Windows Deployment
01

การติดตั้งโปรแกรม

ดาวน์โหลดและคลายไฟล์ชุดติดตั้งลงในเครื่องคอมพิวเตอร์ของคุณ

คำแนะนำด้านความปลอดภัย: ควรติดตั้งไว้ในโฟลเดอร์ เช่น C:\CMT-IPAS และหลีกเลี่ยงโฟลเดอร์ที่มีชื่อเป็นภาษาไทย
02

การขอสิทธิ์ใช้งาน (Licensing)

ระบบจำเป็นต้องมีการลงทะเบียนรหัสเครื่องเพื่อใช้งาน:

  1. รันไฟล์ cmt-ipas.exe
  2. คัดลอกรหัส SERVER HWID ที่แสดงในหน้าต่างโปรแกรม
  3. ส่งรหัสให้ทีมสนับสนุนเพื่อรับไฟล์ license.dat
  4. นำไฟล์ลิขสิทธิ์มาวางในโฟลเดอร์เดียวกับโปรแกรม
03

การเข้าสู่หน้าควบคุม (Dashboard)

จัดการช่องสัญญาณและตรวจสอบสถานะผ่านเบราว์เซอร์:

http://127.0.0.1:19001

Default Login:
Username: admin / Password: password123

หรือคลิกขวาที่ไอคอน ในระบบ System Tray เลือก 🌍 Open Dashboard

04

การตั้งค่ารันอัตโนมัติ

ตั้งค่าให้โปรแกรมทำงานทันทีเมื่อเปิดเครื่อง (Startup):

1. สร้าง Shortcut ของไฟล์โปรแกรม
2. กด Win + R แล้วพิมพ์ shell:startup
3. นำ Shortcut มาวางในโฟลเดอร์นั้น
